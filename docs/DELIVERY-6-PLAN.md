## 1. Goal

Deliveries 1–5 rebuilt the 59 screens of the prototype. Many of their functions were still simulated, or were buttons that only said "coming soon". **Chapter 4 makes every one of them real, as long as Keystone can do it with its own data.**

The following stay placeholders, each with a toast that names the system it needs:
- PDM: "Open in PDM", vault sync;
- Codex: document zip;
- Sage X3: push;
- the remote side of a connector.

The work was split into a foundation plus eight features: planning, whatif, interchange, meetings, exports, settings, kpis and misc. A multi-agent build ran all of them. A usage limit then interrupted it, before the integration, review and documentation steps. **Most of the code is in place**, as the status table below shows.
