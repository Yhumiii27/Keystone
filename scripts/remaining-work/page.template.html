Points restants par domaine

Priorité : celle du responsable produit quand une décision la donne (Bloquant production, Prochaine étape, Plus tard), « À décider » quand il faut d’abord trancher. Effort, pour un développeur qui connaît le code : S < 2 jours, M ≤ 1 semaine, L ≤ 3 semaines, XL > 3 semaines ; les totaux en jours sont un ordre de grandeur (S = 1,5, M = 4, L = 12, XL = 30) sans l’attente des décisions, le travail des autres applications ni la recette.

Méthode : 195 décisions produit, écarts et questions ouvertes des livraisons 1 à 6, backlog, marqueurs du code, spécification et préparation à la production, croisés puis vérifiés dans le code ; 153 candidats déjà réalisés ont été écartés.
